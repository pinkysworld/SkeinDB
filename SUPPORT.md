# Support SkeinDB

If SkeinDB is useful to you and you want to help keep it moving, there are two easy ways to support it:

- GitHub Sponsors is the main option. Once GitHub finishes approving the `pinkysworld` sponsor profile, the repo will show a `Sponsor` button.
- If PayPal is easier, you can use `mip@gmx.biz`.

Support helps pay for things like:

- MySQL and PostgreSQL compatibility improvements
- SkeinAdmin and operator tooling
- documentation, regression tests, and live compatibility checks
- backlog reduction and research-track hardening

If you want to support SkeinDB from a company or research lab, opening an issue or reaching out through the repository profile is completely fine too.
