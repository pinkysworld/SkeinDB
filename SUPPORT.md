# Support SkeinDB

If SkeinDB is useful for your work, you can support ongoing development in two ways:

- GitHub Sponsors: the preferred path for recurring or one-off support. The sponsor profile for `pinkysworld` is being set up and will appear as a GitHub `Sponsor` button once approval is complete.
- PayPal: one-off support can currently be arranged via `mip@gmx.biz`.

Support helps fund work like:

- MySQL and PostgreSQL compatibility improvements
- SkeinAdmin and operator tooling
- documentation, regression tests, and live compatibility verification
- backlog reduction and research-track hardening

If you want to support SkeinDB from a company or research lab, opening an issue or reaching out through the repository profile is also fine.
