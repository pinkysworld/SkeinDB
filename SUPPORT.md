# Support SkeinDB

If SkeinDB is useful to you and you want to help keep it moving, there are a few easy ways to support it:

- **GitHub Sponsors** — recurring, lowest-friction: <https://github.com/sponsors/pinkysworld>
- **PayPal** — one-off donations: <https://www.paypal.com/paypalme/mippinky> (or send directly to `mip@gmx.biz`).

Support helps pay for things like:

- MySQL and PostgreSQL compatibility improvements
- SkeinAdmin and operator tooling
- documentation, regression tests, and live compatibility checks
- backlog reduction and research-track hardening

If you are looking for a **formal commercial relationship** (support contracts
with response-time SLAs, training, architecture reviews, named research-track
sponsorships, or — after 1.0 — hosted SkeinDB or enterprise add-on modules),
please see [COMMERCIAL.md](COMMERCIAL.md) and open a
[commercial inquiry issue][ci].

[ci]: https://github.com/pinkysworld/SkeinDB/issues/new?labels=commercial&title=Commercial%20inquiry
