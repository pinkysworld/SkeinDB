Database Encryption

              
Inspect per-database encryption mode (ENC_OFF, ENC_RANDOM, ENC_MLE_DB) and active key. Master key bytes are never persisted to disk — operators must re-register keys after restart with settings.encryption.register_key.

Switch a database's encryption mode. Switching to ENC_RANDOM or ENC_MLE_DB requires that an active key be registered first.

Register Key

              
Register a 32-byte master key (base64-encoded) for a database. The key lives only in process memory. Re-register on every restart.

Set Active Key

              
Promote a previously registered key as the active key for new writes (does not re-encrypt historical envelopes).

Rotate Key

              
Rotate the active key for a database. Returns a KeyRotationPlan describing the previous and new key IDs and the current mode. Existing envelopes remain readable under historical keys; use the EncryptedValueStore reencryption API to rewrite them off-line.
