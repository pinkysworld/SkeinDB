Getting Started

  1. Enter Base URL + token, then click Connect.
  2. Create a database and table using the guided builders.
  3. Use Browse & Edit for row operations and Cluster Manager for topology.
Every management path is available in two layers: guided forms for day-to-day workflows and advanced JSON/RPC controls for full fidelity.

Keyboard shortcuts: ⌘K Command palette   ⌘↵ Run SQL   Esc Close dialogs
