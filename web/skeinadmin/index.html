Getting Started (phpMyAdmin-style flow)

  1. Enter the server Base URL and optional token, then press Connect.
  2. Pick a database and table from the left tree. The context bar updates as you click.
  3. Use the SQL, Structure, Browse, and RPC tabs to manage every SkeinDB feature.
Tip: If a feature does not have a dedicated panel yet, open RPC Explorer and call the method directly.
