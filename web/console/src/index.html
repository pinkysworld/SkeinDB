SkeinConsole

This is a placeholder UI scaffold.

Planned API endpoints

  • POST /api/v1/sql/exec (SQL runner for admin)
  • POST /api/v1/rpc (SkeinQL v1.0 native RPC)
  • GET /api/v1/q/{query_id} (cacheable prepared queries with ETag)

Planned console features

  • SQL editor + results grid
  • Schema browser (SHOW + INFORMATION_SCHEMA projection)
  • Table browse/edit + CSV import/export
  • Users + grants management
  • Engine ops: checkpoint/compact + dedup and delta stats
  • Compatibility telemetry dashboard + migration hints (MySQL -> SkeinQL)
  • Audit chain verification status
  • Snapshot builder and analytics acceleration controls
  • Wasm UDF management (install/list/permissions)

Start by implementing system.ping on /api/v1/rpc and wiring this UI to call it.
