SkeinDB True Status Matrix¶

Last updated: 2026-04-24 Honest claims: SkeinDB does not provide and does not claim "100% MySQL compatibility." Coverage is measured against the regression corpus at tests/compat/corpus.sql (1658 lines / ~700+ statements) which is exercised on every commit by cluster_rpc::compat_corpus_statements. The surface that is supported is enumerated in docs/MYSQL_COMPAT.md. Anyone reading marketing copy claiming "100% MySQL parity" should treat that as false.

2026-04-24: SkeinAdmin Easy Viewer ships a WYSIWYG schema editor (Design tab). It loads a table via schema.describe_table, lets the operator rename / retype / mark nullable / set default / drop columns inline, computes an ALTER TABLE plan (ADD/DROP/RENAME/MODIFY/CHANGE COLUMN) by diffing original vs draft, previews the plan in-place, and applies statements one at a time via sql.exec (halts on first error). Asset coverage in crates/skeindb/tests/skeinadmin_assets.rs::skeinadmin_easy_design_tab_exposes_wysiwyg_schema_editor. Backend ergonomics: skeindb version now prints a richer banner with format and dialect doc pointers; new skeindb info --data ./data [--json] subcommand prints catalog/storage/port summary for ops use; skeindb serve now prints a startup banner (data dir, storage mode, HTTP/SkeinAdmin/MySQL/PostgreSQL/QUIC/cluster URLs) before binding. Engine::storage_mode_name() is now a public read-only accessor.

Last updated: 2026-04-23 Latest changes: Phase 14/17 cluster movement now computes shard-scoped object manifests from live row versions, preflights destination ValueID coverage with objects.need, pulls only missing objects via objects.pull before changing placement, and returns manifest/progress summaries from cluster.shard.move / cluster.shard.rebalance; MySQL COM_STMT prepare metadata now covers supported projection-level scalar subqueries plus embedded scalar-subquery arithmetic, serve now defaults row persistence to segment/.rseg, the PostgreSQL listener now handles common startup/bootstrap probes including current_database(), current_schema(), SHOW server_version / server_version_num / standard_conforming_strings / max_identifier_length, SHOW transaction isolation level, and SELECT current_setting(...), Phase 20 now has a shipped encryption baseline in skeindb-core::encryption with database-scoped key registration, active key selection, and ENC_RANDOM / ENC_MLE_DB AEAD wrappers, Phase 25 now also exposes partial virtual pg_catalog coverage (pg_database, pg_namespace, pg_type, pg_proc stub, pg_settings, pg_stat_activity) through both sql.exec and the live PG listener, SkeinAdmin’s live surface was reconciled with the runtime (settings.list, telemetry/security navigation, research-config hydration, cluster leave / user revoke, Easy Viewer inline DB creation plus create-table validation/preview, the Forensics panel’s maintenance.audit_* controls, a dedicated CDC subscriptions page with lag visualization, a dedicated Time Travel & Replay page with query.select as_of, maintenance.history.*, and maintenance.replay.* workflows, and live compaction pressure/workload cards backed by stats.snapshot), Phase 21 now includes both reproducible scheduler evaluation artifacts and live scheduler policy controls (maintenance.compaction.*, stats.snapshot.compaction.scheduler, and hard-pressure write backpressure for write-classified SkeinQL/HTTP mutations), and Phase 26 now adds Debian packaging metadata, a signed apt publication path, and a repo-scoped Homebrew tap formula with tag-driven updates.

Phase 19 now also exposes snapshot-based replay bundles via maintenance.replay.export / maintenance.replay.import / maintenance.replay.run and skeindb replay export|verify|run, materializing deterministic verification workspaces under .replay_workspaces with canonical checksums over captured schema+row snapshots plus retained change-event metadata. 2026-04-23 release-candidate hardening: ENC_MLE_DB in skeindb-core::encryption no longer uses a fixed AEAD nonce; the nonce is now HKDF-derived from the database master secret plus the plaintext digest in the same scope as the content key, keeping convergent dedup while removing the fixed-nonce review finding. Replay export now rejects reversed LSN ranges (from_lsn > to_lsn) with invalid_request, and maintenance.replay.import / maintenance.replay.run now bound workspace_id length to at most 128 ASCII chars in addition to the existing character-set check. The docs-site architecture figure path was corrected so crates/skeindb/tests/docs_site_assets.rs::architecture_figure_path_resolves is green again and cargo test --workspace passes end-to-end.

This matrix reconciles runtime reality with backlog checklists.

Interpretation: - Implemented: shipped in runtime and exercised by tests. - Partial / Prototype: usable surfaces exist, but hardening/completeness tasks remain open. - Planned: backlog intent exists, but no meaningful runtime implementation yet.

WebSocket transport and durable cursors remain open.

The shared executor now also serves partial virtual pg_catalog tables for pg_database, pg_namespace, pg_type, pg_proc (stub), pg_settings, and pg_stat_activity. RowDescription now advertises shared-engine BOOL / INT8 / FLOAT8 / TEXT / DATE / TIME / TIMESTAMP / JSONB / BYTEA / UUID metadata when schema or literals expose those types, and bytes rows normalize to PG bytea hex text on the wire. Listener on port 5432 (configurable via --pg flag). SCRAM-SHA-256 auth (T401), PG session state (T402), PG SQL dialect parser (T404), broader catalogs (T409), and broader driver coverage remain open.
